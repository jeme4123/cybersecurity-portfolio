## How to Run It Locally

1. Clone the repository:

```bash
git clone https://github.com/jeme4123/cybersecurity-portfolio.git
```

2. Enter the project folder:

```bash
cd cybersecurity-portfolio
```

3. Install the required packages:

```bash
npm install
```

On Windows PowerShell, use this command if npm scripts are blocked:

```powershell
npm.cmd install
```

4. Start the development server:

```bash
npm run dev
```

On Windows PowerShell, you can use:

```powershell
npm.cmd run dev
```

5. Open the local address displayed in the terminal, usually:

```text
http://localhost:5173/
```
